# Segurança

Não publique vulnerabilidades, credenciais, sessões, dados de clientes ou evidências de produção em issues públicas.

Este repositório não deve conter:

- arquivos `.env`;
- tokens ou chaves de API;
- chaves SSH privadas;
- sessões Baileys;
- backups ou bancos;
- conversas e documentos de clientes;
- código ou artefatos privados do fazer.ai Pro.

Antes de cada publicação, revise o diff e execute a verificação de segredos definida no pipeline do projeto.
