# Homologação e aceite

## Infraestrutura

- [ ] Containers necessários saudáveis.
- [ ] Reinício da VPS não perde dados ou configurações.
- [ ] TLS válido.
- [ ] Volumes persistentes confirmados.
- [ ] Backup executado com sucesso.
- [ ] Restauração documentada e testada conforme o plano.

## Agente

- [ ] Identidade e tom corretos.
- [ ] Não inventa políticas, preços ou disponibilidade.
- [ ] Responde uma pergunta por vez quando aplicável.
- [ ] Transfere situações proibidas para humano.
- [ ] Não confirma uma ação antes do retorno da ferramenta.
- [ ] Não expõe detalhes técnicos.

## Conhecimento

- [ ] Todos os documentos estão `READY`.
- [ ] Pergunta exclusiva da base respondida corretamente.
- [ ] Ausência de resposta gera conduta segura.
- [ ] Conteúdo de outro cliente não está acessível.

## Chatwoot e canal

- [ ] Mensagem incoming chega ao Chatwoot.
- [ ] Agente recebe a mensagem.
- [ ] Resposta outgoing aparece na conversa.
- [ ] Transferência humana funciona.
- [ ] Nota privada e resumo funcionam quando contratados.
- [ ] Sessão Baileys reconecta e gera alerta de desconexão.

## Recursos por plano

- [ ] Quantidade de agentes respeitada.
- [ ] Quantidade de canais respeitada.
- [ ] STT testado quando incluído.
- [ ] TTS testado quando incluído.
- [ ] Calendar testado quando incluído.
- [ ] Drive testado quando incluído.
- [ ] Follow-up testado quando incluído.
- [ ] Asaas testado quando incluído, sem cobrança real acidental.
- [ ] Integrações personalizadas testadas quando incluídas.
- [ ] Teste de carga realizado quando incluído.

## Observabilidade

- [ ] Trace completo visível no Langfuse.
- [ ] Tokens e latência presentes.
- [ ] Chamadas de ferramentas identificáveis.
- [ ] Erro de teste aparece nos logs e alertas.
- [ ] Nenhum segredo aparece em trace ou log.

## Aprovação

- [ ] Evidências anexadas.
- [ ] Pendências registradas.
- [ ] Cliente aprovou a homologação.
- [ ] Binary Insights autorizou a produção.
